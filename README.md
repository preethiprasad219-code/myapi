\# FastAPI Todo API



A simple Todo API built using FastAPI, Python, SQLAlchemy, and PostgreSQL.



\## Features



\- Get all todos

\- Add a new todo

\- Delete a todo

\- Store todos in PostgreSQL database

\- SQLAlchemy database integration

\- Interactive API documentation using Swagger UI



\## Technologies Used



\- Python

\- FastAPI

\- Uvicorn

\- SQLAlchemy

\- PostgreSQL

\- Psycopg2
